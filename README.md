# 跨境订单对账练习

用 30 笔模拟订单练习三件事：用 SQL 找出对账差异，用 Python 比较人工送审规则，再用 AI 根据订单和渠道流水写复核说明。

## 项目结果

- SQL：按订单号和币种匹配付款，导出 6 笔异常。其中 4 笔未匹配到同币种付款，2 笔金额不一致。另用渠道流水号排查疑似重复记录。
- Python：宽规则送审 6 笔、误报 2 笔、漏报 0 笔；窄规则送审 5 笔、误报 2 笔、漏报 1 笔。提高金额门槛省下的名额，恰好是应当复核的一笔。
- AI：v2 在 8 个模拟案例中有 7 个全部通过。v3 修正了把账面汇总当成已确认实付的问题，定向复测的 2 例都通过。

## 如何复现

1. 用 SQLite 工具打开 `recon_practice.db`，在 `reconciliation.sql` 中选择要运行的查询。
2. 在项目目录打开 PowerShell，运行：

   ```powershell
   py .\compare_review_rules.py
   ```

   脚本读取 `reconciliation_all.csv`，输出送审数量及误报、漏报的订单号。
3. 用 `recon_prompt.md` 中的提示词复测 AI 说明，评分和案例结论见 `note.md`。

项目使用模拟数据。AI 只生成复核说明，实际付款笔数、退款和调账仍需依据原始流水确认。
